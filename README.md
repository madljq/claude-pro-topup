"自助充值"这个词就是从这个缝里长出来的。不过它在中文语境里其实指两件不同的事，风险差得很远：

## 常见问题

**会不会拿到别人的账号？**
看你买的是哪种服务。如果是"给自己的账号开通"，账号自始至终是你的；如果价格低得离谱，多半卖的是成品号或共享号，那类东西的对话记录不私密，掉订阅也没有申诉路径。

**需要把密码给平台吗？**
按平台说明，走的是浏览器插件抓取 Session / Cookie 的方式，不需要密码。但要知道 Session 本质上就是登录凭证，它的安全边界取决于平台怎么用它，所以别在共用电脑上操作。

**多久生效？**
多数订单几分钟到半小时，慢的时候会更久。超过一两个小时还显示处理中，直接找客服。

**开通失败了怎么办？**
平台侧的失败一般会走退款流程。如果失败原因是你本地网络环境不达标，退款之后换个住宅 IP 重新下单，成功率会高不少。

**Pro 和支持 API 是一回事吗？**
不是。Pro 是 claude.ai 聊天端的订阅，不含 Console 的 API 额度，两者钱包分开算。
